# Case study content

Drop `.md`/`.mdx` files in this directory to publish case studies. Schema is defined in `src/content.config.ts` (the `caseStudies` collection).

Required frontmatter: `title`, `client`, `summary`, `publishDate`. Optional: `logo`.

No case study listing page exists yet (v1 ships the homepage only) — this is scaffolded so the collection can be wired up without restructuring later.
